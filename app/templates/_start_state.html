So kommst du zur passenden RVK-Stelle

  1. Begriff eingeben – ein Schlagwort oder Thema, so wie du es formulieren würdest.
  2. Erweiterung und Hauptgruppen prüfen – unpassende Begriffe mit × entfernen, bei Bedarf links die Hauptgruppen wählen.
  3. Notation in RVK-Online prüfen – die Vorschläge sind eine Orientierung, die Entscheidung triffst du.

Beispielsuchen:

    {% for term, hint in [("Klimawandel", ""), ("Umwelttechnik", ""), ("Konfliktmanagement", ""), ("Bank", "mehrdeutig")] %}
  • {{ term }}{% if hint %} ({{ hint }}){% endif %}
    • {% endfor %}
